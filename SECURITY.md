# Security policy

## Reporting a vulnerability

Do not open a public issue for a suspected vulnerability or exposed credential.

Email **security@drooly.ai** with:

- the affected repository and revision;
- a concise description and realistic impact;
- reproduction steps or a minimal proof of concept; and
- any suggested mitigation.

Do not access data that is not yours, disrupt production, perform social
engineering, publish secrets, move funds, or test against third parties without
their permission. We will acknowledge a complete report as soon as practical,
triage it privately, and coordinate disclosure when a fix is available.

This policy does not create a bug-bounty promise or authorize activity that
would otherwise be unlawful.
