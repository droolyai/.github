# Community code of conduct

We want technical and creative collaboration to be direct, useful, and safe.

Be respectful. Critique work rather than people. Do not harass, threaten, dox,
impersonate, discriminate, spam, manipulate engagement, promote scams, or solicit
wallet secrets. Label adult or sensitive material where a project permits it;
never post it where the repository rules prohibit it.

Maintainers may edit, hide, lock, or remove contributions that violate these
standards and may restrict participation when necessary to protect the community.
Report sensitive conduct issues privately to **conduct@drooly.ai**.
