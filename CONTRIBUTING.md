# Contributing

Thanks for helping improve a drooly.ai project.

1. Read the repository README, license, and local `AGENTS.md` before changing code.
2. Open an issue for material product or protocol changes before investing in a large patch.
3. Keep pull requests focused, explain the user-facing outcome, and include proportionate tests.
4. Never commit credentials, private keys, wallet seeds, private user data, or unpublished media.
5. Do not add claims about deployed networks, tokens, contracts, storage, or partnerships without verifiable identifiers.
6. Follow the repository license. Some projects are source-available rather than open source.

Security vulnerabilities must follow [SECURITY.md](SECURITY.md) instead of the public issue tracker.
